# Carolina Lopes — Fulham FC portfolio

A responsive one-page portfolio and creative job application built with plain HTML, CSS and JavaScript.

## Preview

Open `index.html` in a browser, or start any simple local web server in this folder.

## Publish with GitHub and Netlify

1. Create a new, empty GitHub repository.
2. On GitHub, choose **Add file** → **Upload files**.
3. Open the `london-city-portfolio` folder and upload everything inside it. Make sure `index.html` is at the top level of the repository, not inside another folder.
4. In Netlify, choose **Add new project** → **Import an existing project**.
5. Select the GitHub repository.
6. Leave the build command empty and set the publish directory to `.`.
7. Select **Deploy**.

Every later push to the GitHub repository will update the Netlify website automatically.

## Edit

- Main content: `index.html`
- Colours and layout: `styles.css`
- Menu, scrolling and photo viewer: `script.js`
- Images: `assets/`

No OpenAI API key or other secret is required.
